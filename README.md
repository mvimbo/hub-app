# StreamVault Android / TV

Standalone installable StreamVault for Android phones, tablets and Android / Google TV. Source code, native Android project, tests, compatible launch-intro videos and build instructions are in [StreamVault-Android-TV-source.zip](https://github.com/mvimbo/hub-app/raw/refs/heads/main/StreamVault-Android-TV-source.zip). The five-second launch intro is centered at its original square proportions on black; there is no Skip button.

## Build it

1. Download and extract the source archive.
2. Follow the build prerequisites in the archived README.
3. Set your own `VITE_TMDB_API_KEY` in a private `.env` file before building to enable movie and TV metadata. Do not commit the key.
4. Run `pnpm install` and `pnpm run android:sync`, then `cd android && ./gradlew testDebugUnitTest assembleDebug`.

The APK generated by that command is a sideloadable debug build, not a Play Store release. The standalone app includes a device-local HTTP/CONNECT filter and popup blocking; it does not decrypt HTTPS and cannot remove every ad. News/sports providers and all playback are still subject to their own availability and permissions.
